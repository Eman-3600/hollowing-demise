# Hollowing Demise

Hollowing Demise is a Fabric mod for Minecraft 1.21.11. It causes dead players to "go hollow", becoming frail specters that consume the essence of experience rather than food. Hollow players can use essence to heal and become ethereal, but their physical form burns in the daylight.

## Installation Notes

When cloning the project, make sure to run the runDatagen task before running the client or server or building the project.
